# GOOL Football (оригинальный V5 + LIVE V4) на Bot-Hosting.net

**Экспериментальный single-process запуск готовых футбольных мозгов GOOL.**
Оригинальные файлы `football_v5_shadow.py`, `football_v5_production.py`,
`live_goal_brain_v4.py` перенесены **без изменений** из main.
Данные собирает облегчённая оболочка, вместо оригинального процесса
`monkey_start.py` с отдельными демонами.

## Почему этот вариант предпочтительнее старого Lite

- PREMATCH: подлинный `forecast_from_history()` (силы соперников, Poisson
  score grid), далее подлинный `production_v5_picks()` и его лимиты odds,
  quality, p, edge, EV. **Нет отдельного Lite-калькулятора вероятностей.**
- Прематчевый источник: Flashscore event odds, но каждая нормализованная пара
  исходов должна принадлежать одному букмекеру/линии. Сейчас адаптированы
  FT totals, BTTS, 1X2. Остальные рынки оригинального V5 (например, командные
  тоталы через отдельный поток 1xBet) ещё не подключены к облегчённому потоку.
- LIVE: **без изменений** `evaluate_live_goals()` из Brain V4, свежие
  Flashscore и выборочная проверка 365Scores/FotMob. Защитные правила V4
  сохраняются. Текущие LIVE-котировки 1xBet дополнительно сверяются с
  матчем и счётом. Нет автоматического ослабления V4 confidence.
- Выделенный Python-процесс, без хоккея, баскетбола, обучения моделей,
  Chromium, sklearn, pandas, numpy.
- Telegram: `/start`, `/status`, `/audit`, `/prematch`, `/live`,
  `/journal`, `/express`, `/dayreport`, `/oddscheck`, `/stop`.
- Ставки после завершения матча сверяются в том числе для оригинальных
  рынков V5 (`match_total`, `home_total`, `away_total`, `btts`,
  `match_1x2`); записи хранятся на диске контейнера.
- `SHADOW` оставлен как значение по умолчанию: сбор и `/audit` без
  автоматических сообщений. `ACTIVE` доступен, когда проверены источник
  котировок, память и текущие сигналы.

## Установка на существующий Bot-Hosting.net

- GitHub repository: `superprey3-wq/gool_bot2`
- Branch: `bot-hosting-lite`
- Python: `3.11`
- Startup: `bot_hosting_lite.py`
- `requirements.txt`: только Pillow
- Секреты `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` хранятся в интерфейсе
  хостинга, никогда в GitHub и не в чат-скриншотах.
- Режим: `GOOL_FOOTBALL_LITE_MODE=shadow` до проверки.
- Изменения подтягиваются при рестарте, если этот пункт включён в настройках.

После перезапуска в консоли:
`GOOL_FOOTBALL_ONLY_STARTED`,
`GOOL_LITE_FOOTBALL_PRE`,
`GOOL_LITE_FOOTBALL_LIVE`,
`GOOL_FOOTBALL_HEALTH`.

После 20–30 минут в Telegram: `/status`, `/audit`, `/prematch`,
`/oddscheck`. Тест `/oddscheck` проверяет лишь индекс 1xBet, но не
гарантирует наличие цены на конкретную ставку.

## Жёсткие лимиты бесплатного сервера

- `GOOL_LITE_FOOTBALL_PREMATCH_MAX=5`: до 5 игр за 10-минутный цикл;
  выборка перемещается по списку, нельзя заявлять, что обработаны *все*
  матчи суток.
- `GOOL_LITE_FOOTBALL_LIVE_MAX=4`: 4 игры за 3-цикла наблюдения, затем
  переход к следующей группе; в отличие от полноразмерного сервера, возможны
  пропуски сигналов при множестве одновременных матчей.
- Не подтверждено: 24-часовая устойчивая работа оригинального V5/V4 с
  реальной нагрузкой на 25% CPU / 256 МБ RAM, доступность внешних сайтов из
  сети Bot-Hosting.net и достоверность цен в конкретный LIVE-момент.
- GitHub Actions тестирует логику на независимых синтетических данных, а
  отдельный network diagnostic демонстрирует лишь доступность источников
  *из GitHub Actions*, не с хостинга пользователя.
- Нельзя гарантировать количество ставок или прибыль. Вероятности V5
  обозначены оригинальными авторами как некалиброванные.

## Безопасное включение сигналов

Только после проверки источников и нормальных исходов в SHADOW установи
`GOOL_FOOTBALL_LITE_MODE=active` и перезапусти.
Защита требует реальные paired bookmaker prices и правильную идентичность
матчей. Отсутствие ставок — допустимый результат строгих фильтров, не повод
отправлять непроверенную ставку.
